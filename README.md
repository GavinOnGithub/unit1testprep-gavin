# Unit 1 Test Prep: StringMathPractice

This repository is a **starter project**. It contains `StringMathPractice.java`, a class with
String and Math practice methods for you to complete. Do not work in this repository directly;
use it as the starting point for **your own** repository.

## Setup with GitHub Desktop

### 1. Clone this repository
1. Open GitHub Desktop and choose **File > Clone repository...**
2. Select the **URL** tab and paste this repository's URL (or find it under the **GitHub.com** tab).
3. Choose a local folder and click **Clone**.

### 2. Create your own repository on GitHub
1. Go to [github.com/new](https://github.com/new).
2. Name it (for example `unit1testprep-yourname`).
3. Leave it **empty**: do not add a README, .gitignore, or license.
4. Click **Create repository** and copy its URL.

### 3. Change the origin to point to your repository
1. In GitHub Desktop, choose **Repository > Repository settings...** (Ctrl+, on Windows, Cmd+, on Mac).
2. Select the **Remote** tab.
3. Replace the **Primary remote repository (origin)** URL with the URL of **your** repository.
4. Click **Save**.

### 4. Push to your repository
1. Click **Publish branch** / **Push origin** (or **Repository > Push**).
2. Refresh your repository page on GitHub to confirm the files appear.

From now on, commit and push your work to your own repository.

## The assignment
1. Open `StringMathPractice.java` in your editor.
2. Complete the constructors and every method marked `// TODO`.
3. Write code in `main` that creates objects and tests each method.
4. Commit and push your work regularly.

Compile and run from a terminal with:

```
javac StringMathPractice.java
java StringMathPractice
```
